# User guide

## Copy cleanly in Chrome

Load the extension, open its popup, enable the product and desired providers, then use ordinary `Ctrl+C` on a selected assistant response. Paste normally. Unknown websites are untouched unless you enable the generic formatter for that exact site and grant its optional permission.

## Paste into Word or Outlook

Start the Windows companion. Keep automatic formatting enabled. Copy from a supported provider in the browser and paste normally into the native application. The tray process acts only when the clipboard includes a recognized AI source URL.

## Build document files

Open Document Studio, paste or type source, choose input format (Auto is usually sufficient), choose a template, select outputs, and press **Generate files**. The first generation creates a project. Later changed content creates a new version. Download individual files or use **Export** for the source, artifacts, verification previews, and checksum manifest.

Green **Verified** means a rendered page was checked. Amber **Structural** means the file package parsed but visual rendering was unavailable. Red **Failed** means the file must not be treated as verified.

## Templates

- Standard business brief: reports, proposals, and common office documents.
- Google Docs default: Arial-based portability.
- Compact reference guide: dense instructions and checklists.
- Narrative proposal: longer serif body copy.

## Delete data

Open History, choose the trash action, and confirm. This removes project metadata and its version/artifact directory. Export first if you need a recoverable copy.
