# Changelog

## 0.2.0 - 2026-08-09

- Added local Document Studio with React UI, FastAPI API, and CLI.
- Added Markdown/HTML/plain semantic parsing.
- Added DOCX, PDF, Markdown, and plain-text generation with four templates.
- Added immutable source versions, local artifact metadata, deletion, and checksum exports.
- Added Word/Poppler render verification with truthful three-state results.
- Added loopback/token startup guards, HTTP-only access session, rate limiting, idempotency, security headers, and metadata-only audit events.
- Added Docker/Compose, Windows launch/verification scripts, CI, fixtures, tests, and audit documentation.
- Preserved and regression-tested the existing Chrome MV3 extension and Windows clipboard companion.
- Added dependency-contained Windows Studio/companion folders with tray lifecycle and per-user startup control.
- Added bounded HAI connector/OpenAPI contract and guarded production ngrok launcher.
- Added random memory-only browser sessions, SQLite WAL/indexes, serialized Word rendering, Docker runtime acceptance, and fail-fast PowerShell gates.
